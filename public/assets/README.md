# Recursos gráficos

Estos SVG son ilustraciones independientes para que la landing funcione sin depender de imágenes externas.

- Sustituye `person-1.svg`, `person-2.svg` y `person-3.svg` por los retratos definitivos del hero. Actualiza la propiedad `image` del arreglo `people` en `../index.html` si cambia la extensión o el nombre.
- Sustituye `sam-altman.svg` y los `testimonial-*.svg` por fotografía autorizada manteniendo la proporción visual (retrato vertical o cuadrado según el archivo).
- El video se preparó como contenedor CSS en `index.html`; conecta aquí un MP4, Vimeo o YouTube cuando exista.

Todos los recursos gráficos son ilustraciones abstractas, no representan personas reales.
